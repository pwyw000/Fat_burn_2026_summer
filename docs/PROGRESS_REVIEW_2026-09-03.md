## 4. 模型结论（稳定的几条）

**恢复（最干净）**

- 睡眠 vs 恢复：Spearman ρ = 0.40，p = 0.009（n = 41）。
- OLS（n = 36）：+1 h 睡眠 ≈ **+8.6 recovery 点**（95% CI 4.1–13.0，p = 0.0004）。
- ElasticNet 只留下三件事：睡眠（+）、前一日 Cheat（−）、前一日热量（−）。
- Cheat 次日恢复 **48% vs 69%**（p = 0.003）。

**体脂（周粒度才有用）**

- 日级体重 Ridge LOO R² 为负：不要用某天少吃多少来预测次日秤。
- 7 个完整周：周均蛋白 vs Δ 体脂% **ρ = −0.86（p = 0.012）**；力量次数 vs Δ 体脂% **ρ = −0.76（p = 0.046）**。蛋白打满的周，秤掉得少、脂肪掉得多（水分/糖原/瘦体重留住了）。

**跑步功率**

- 效率随时间上升（ρ = 0.64，p = 0.048）。
- 最差一跑：8/9，睡 4h46，配速 12:15，效率 30.8。
- HR vs 配速 ρ = −0.64：用尽全力调配速，而不是待在轻松有氧带。

## 6. 接下来怎么提高功率和效率

1. **睡眠 7.5–8 h** — 恢复模型的主开关；Cheat 当晚也要睡够。
2. **蛋白 160–180 g × 6 个 Slow Carb 日** — 周均蛋白是体脂下降最强相关。
3. **力量 4×、20 min 超级组** — 新课表：一肩臂 / 二胸腹 / 四背+后束 / 五下肢；午饭前优先。
4. **跑日吃满新 §3.2** — 少吃 + 均 HR 172 = 贵的 strain、差的有氧适应。
5. **轻松跑 HR 约 155–165** — 绿恢复且睡 ≥7 h 才允许略提配速。
6. **周目标 −0.5% 体重**（约 0.85 lb/周 @170 lb），用体脂% 验证掉的是脂肪。近 162 lb 停止扩大缺口。
