## 1. 能量预算（Mifflin–St Jeor · 按当前 ~175 lb 计算）

**原则：** 力量课实际消耗按你估计 **≈100 kcal/次**（非 150–200），**不应高估 TDEE**。主要运动消耗来自 **跑步**；力量首要价值是 **保肌**。

**NEAT 是什么：** *Non-Exercise Activity Thermogenesis*（非运动活动产热）= 除开正式训练外的日常消耗（走路、站立、家务、办公等）。  
本计划的「日常消耗」档 = **BMR + 日常活动**（不含跑步/力量）；已按你的 **Whoop 数据校准为 2,100 kcal/日**（不再用 BMR×1.40≈2,430）。再 **另加** 当日力量 **+100** / 跑步 **+Garmin**。

| 项目 | 公式 / 假设 | 数值 |
|---|---|---|
| 体重 | ~175 lb | **~79.4 kg** |
| 身高 | 6'0" | **183 cm** |
| 年龄 | — | **41 岁** |
| **BMR** | 10×kg + 6.25×cm − 5×age + 5（男） | **≈ 1,735–1,740 kcal/日**（公式参考） |
| **日常消耗（Whoop NEAT 档）** | **Whoop 校准**（BMR+日常活动，不含正式训练） | **2,100 kcal/日** |
| **力量消耗** | 4×/周 × **100 kcal** | **≈ +57 kcal/日**（均摊） |
| **跑步消耗** | 2×/周 × **550–750 kcal**（Garmin；取 **650** 均摊） | **≈ +185 kcal/日**（均摊） |
| **TDEE（周均）** | 2,100 + 运动均摊 | **≈ 2,340–2,350 kcal/日** |
| 周脂肪目标 | **当前体重(lb) × 1%** | 例：175 lb → **1.75 lb/周** |
| **周赤字（全周总目标）** | 周目标减重组 × **3,500 kcal/lb** | 1.75 lb → **≈ 6,125 kcal/周** |
| **Slow Carb 日赤字** | 周赤字 ÷ **6**（**周六 Cheat 不计**） | **≈ 1,020 kcal/日** |
| **Slow Carb 日目标摄入** | **当日 TDEE − Slow Carb 日赤字** | 见下表 |

> **缺口怎么算：** 全周仍要减掉 **W×1%×3500 kcal**，但 **周六 Cheat 不吃缺口**，所以 **Sun–Fri 共 6 天**各承担 **周赤字 ÷ 6**（不是 ÷ 7）。  
> **Cheat 若明显超标：** 周六若比维持多吃 **+1,000–2,000 kcal**，实际周赤字会缩小 → 周均体重可能只降 **0.7–0.9%**；要么 Cheat 略收，要么接受略慢（见 §1.1）。  
> **体重会变：** 每 1–2 周用 **Withings 周均体重** 重算（见 §1.1）。

### 1.1 滚动重算（体重一直在变）

每周日（或周复盘）用 **本周 Withings 周均体重** `W`（lb）更新：

| 步骤 | 公式 |
|---|---|
| 1. BMR | 10×(W×0.4536) + 6.25×183 − 5×41 + 5（参考） |
| 2. 日常消耗 | **Whoop NEAT 档 = 2,100**（有新 Whoop 周均则更新此数） |
| 3. 周目标减重组 | **W × 1%**（lb） |
| 4. 周赤字 | 周目标减重组 × **3,500** kcal |
| 5. **Slow Carb 日赤字** | 周赤字 ÷ **6**（**周六 Cheat 除外**） |
| 6. 当日 TDEE | 2,100 + 当日运动（力 **+100** / 跑 **+Garmin** / 休 **+0**） |
| 7. **Slow Carb 日目标摄入** | **当日 TDEE − Slow Carb 日赤字** |
| 8. **周六 Cheat** | **不设上限**；不贡献赤字；周日恢复 Slow Carb |

**例（W = 174.7 lb · Whoop 日常 2,100 · 力量 +100）：**

| 项目 | 数值 |
|---|---:|
| Whoop 日常消耗 | **2,100** |
| 周目标 | 174.7 × 1% = **1.75 lb** |
| 周赤字 | 1.75 × 3,500 = **6,115 kcal** |
| **Slow Carb 日赤字** | 6,115 ÷ **6** = **1,019 kcal** |
| 力量日 TDEE | 2,100 + **100** = 2,200 → 目标 **≈ 1,181**（取整 **1,150–1,300**） |
| 跑步日 TDEE | 2,100 + 650 = 2,750 → 目标 **≈ 1,731**（取整 **1,700–1,900**） |
| 纯休 Slow Carb 日 | 2,100 → 目标 **≈ 1,081**（取整 **1,050–1,200**） |
| **周六 Cheat** | 不计赤字 |

> **注意：** 力量日 ~1,200 kcal 偏紧——**蛋白 160 g 优先**（虾/干贝/粉），豆可略减。若 Whoop 显示掉秤过快或恢复持续红，按 `ADJUSTMENT_RULES.md` **回热量**，不要死磕 1%。

**Cheat 超标时的修正（可选）：**

若周六估计净 surplus **+S kcal**（比维持多吃），则 6 天各承担：

**Slow Carb 日赤字 = (周赤字 + S) ÷ 6**

例：S ≈ 1,500 → (6,125 + 1,500) ÷ 6 = **1,271 kcal/日**（6 天更严）。若不加大 6 天缺口，则接受本周有效速率 **< 1%**。

**体重下降后缺口自然变小（6 天制 · 例）：**

| 周均体重 | 周目标 | Slow Carb 日赤字（÷6） | 说明 |
|---:|---:|---:|---|
| 175 lb | 1.75 lb/周 | **1,020 kcal** | 当前档 |
| 170 lb | 1.70 lb/周 | **992 kcal** | BMR 也略降 |
| 165 lb | 1.65 lb/周 | **963 kcal** | 近 12% 目标区 |
| 160 lb | **停扩大缺口** | +150–250 kcal 吃回去 | 触地板规则 |

> **1% 是「秤上体重」目标，不全是纯脂肪：** 1.75 lb/周里常有 **0.7–1.2 lb 脂肪 + 水分/糖原**。看 **Withings 体脂% 周均** 验证是否在掉脂；若体重降但体脂% 不动，按 `ADJUSTMENT_RULES.md` Case B/C 微调。

> 体重变化后每 2 周用新晨重确认 BMR；**力量固定按 100 kcal/次**，跑步按 Garmin 实绩。

|---|---:|---:|---|

## 3. Slow Carb 食谱（非 Cheat Day）

邮件必须给出**完整一日清单**（早/午/晚/加餐），每项有 **g/个/杯 + 约 kcal + 约蛋白 g**。  
**按训练日直接套用 §3.1 或 §3.2 固定范例**，再按昨日 Nutrition 缺口微调（例：蛋白差 15 g → 多加 1 勺粉）。

**Slow Carb 硬性排除：** 白米、白面、面包、土豆、水果（跑后 ½ 根香蕉例外）、糖、果汁、奶/酸奶/奶酪、油炸食品、酒精。

**饮料：** 水、黑咖啡、无糖汽水 **不限**。

**调味（照抄可用）：** 盐、黑胡椒、蒜粉、辣椒粉、孜然、柠檬/青柠汁、低钠酱油 **1 茶匙**、苹果醋。

## 4. Cheat Day（周六）

- 全天可吃：披萨、甜点、酒、白碳、奶类等 Slow Carb 禁止项。  
- **不设热量上限**；尽量 **1 日** 而非 spillover 到周日。  
- **周日早餐起** 恢复 Slow Carb 模板；邮件周日须写「Cheat 后回归清单」。  
- 若 Cheat 后周日 Withings 体重升 >2 lb：周日仍正常吃 Slow Carb 档，**不加码缺口**（多半是水分/糖原）。

## 6. 参考公式（Agent 重算用）

```
BMR（男）= 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 5   ← 参考
日常消耗 = Whoop NEAT 档 = 2100                            ← 你校准的值
当日运动：力量 +100 · 跑步 +Garmin · 休息 +0
当日 TDEE = 2100 + 当日运动
周目标减重组(lb) = 当前周均体重(lb) × 1%
周赤字 = 周目标减重组 × 3500
Slow Carb 日赤字 = 周赤字 ÷ 6
Slow Carb 日目标摄入 = 当日 TDEE − Slow Carb 日赤字
周六 Cheat：不设上限，不扣赤字
```
