## 1. 能量预算（Mifflin–St Jeor · 按当前 ~170 lb 计算）

**原则：** 力量课实际消耗按你估计 **≈100 kcal/次**（非 150–200），**不应高估 TDEE**。主要运动消耗来自 **跑步**；力量首要价值是 **保肌**。

**NEAT 是什么：** *Non-Exercise Activity Thermogenesis*（非运动活动产热）= 除开正式训练外的日常消耗（走路、站立、家务、办公等）。  
本计划的「日常消耗」档 = **BMR + 日常活动**（不含跑步/力量）；已按你的 **Whoop 数据校准为 2,100 kcal/日**（不再用 BMR×1.40≈2,430）。再 **另加** 当日力量 **+100** / 跑步 **+Garmin**。

| 项目 | 公式 / 假设 | 数值 |
|---|---|---|
| 体重 | ~170 lb | **~77.1 kg** |
| 身高 | 6'0" | **183 cm** |
| 年龄 | — | **41 岁** |
| **BMR** | 10×kg + 6.25×cm − 5×age + 5（男） | **≈ 1,715 kcal/日**（公式参考） |
| **日常消耗（Whoop NEAT 档）** | **Whoop 校准**（BMR+日常活动，不含正式训练） | **2,100 kcal/日** |
| **力量消耗** | 4×/周 × **100 kcal** | **≈ +57 kcal/日**（均摊） |
| **跑步消耗** | 2×/周 × **550–750 kcal**（Garmin；取 **650** 均摊） | **≈ +185 kcal/日**（均摊） |
| **TDEE（周均）** | 2,100 + 运动均摊 | **≈ 2,340–2,350 kcal/日** |
| 周脂肪目标 | **当前体重(lb) × 0.5%** | 例：170 lb → **0.85 lb/周** |
| **周赤字（全周总目标）** | 周目标减重组 × **3,500 kcal/lb** | 0.85 lb → **≈ 2,975 kcal/周** |
| **Slow Carb 日赤字** | 周赤字 ÷ **6**（**周六 Cheat 不计**） | **≈ 495 kcal/日** |
| **Slow Carb 日目标摄入** | **当日 TDEE − Slow Carb 日赤字** | 见下表 |

> **缺口怎么算：** 全周仍要减掉 **W×0.5%×3500 kcal**，但 **周六 Cheat 不吃缺口**，所以 **Sun–Fri 共 6 天**各承担 **周赤字 ÷ 6**（不是 ÷ 7）。  
> **Cheat 若明显超标：** 周六若比维持多吃 **+1,000–2,000 kcal**，实际周赤字会缩小 → 周均体重可能只降 **0.3–0.4%**；要么 Cheat 略收，要么接受略慢（见 §1.1）。  
> **体重会变：** 每 1–2 周用 **Withings 周均体重** 重算（见 §1.1）。  
> **2026-09-03 起 −1% → −0.5%：** 复盘见 `docs/PROGRESS_REVIEW_2026-09-03.md`。力量日不再用 ~1,200 kcal 紧档。

### 1.1 滚动重算（体重一直在变）

每周日（或周复盘）用 **本周 Withings 周均体重** `W`（lb）更新：

| 步骤 | 公式 |
|---|---|
| 1. BMR | 10×(W×0.4536) + 6.25×183 − 5×41 + 5（参考） |
| 2. 日常消耗 | **Whoop NEAT 档 = 2,100**（有新 Whoop 周均则更新此数） |
| 3. 周目标减重组 | **W × 0.5%**（lb） |
| 4. 周赤字 | 周目标减重组 × **3,500** kcal |
| 5. **Slow Carb 日赤字** | 周赤字 ÷ **6**（**周六 Cheat 除外**） |
| 6. 当日 TDEE | 2,100 + 当日运动（力 **+100** / 跑 **+Garmin** / 休 **+0**） |
| 7. **Slow Carb 日目标摄入** | **当日 TDEE − Slow Carb 日赤字** |
| 8. **周六 Cheat** | **不设上限**；不贡献赤字；周日恢复 Slow Carb |

**例（W = 169.6 lb · Whoop 日常 2,100 · 力量 +100）：**

| 项目 | 数值 |
|---|---:|
| Whoop 日常消耗 | **2,100** |
| 周目标 | 169.6 × 0.5% = **0.85 lb** |
| 周赤字 | 0.85 × 3,500 = **2,968 kcal** |
| **Slow Carb 日赤字** | 2,968 ÷ **6** = **495 kcal** |
| 力量日 TDEE | 2,100 + **100** = 2,200 → 目标 **≈ 1,705**（取整 **1,600–1,800**） |
| 跑步日 TDEE | 2,100 + 650 = 2,750 → 目标 **≈ 2,255**（取整 **2,150–2,350**） |
| 纯休 Slow Carb 日 | 2,100 → 目标 **≈ 1,605**（取整 **1,500–1,700**） |
| **周六 Cheat** | 不计赤字 |

> **注意：** 蛋白 **160 g 优先**（虾/干贝/粉）。新档比旧 ~1,200 力量日松一截——用豆和橄榄油把热量吃满，不要继续按旧 1,200 执行。若 Whoop 显示掉秤过快或恢复持续红，按 `ADJUSTMENT_RULES.md` **再回热量**，不要加码缺口。

**Cheat 超标时的修正（可选）：**

若周六估计净 surplus **+S kcal**（比维持多吃），则 6 天各承担：

**Slow Carb 日赤字 = (周赤字 + S) ÷ 6**

例：S ≈ 1,500 → (2,975 + 1,500) ÷ 6 = **746 kcal/日**（6 天更严）。若不加大 6 天缺口，则接受本周有效速率 **< 0.5%**。

**体重下降后缺口自然变小（6 天制 · 例）：**

| 周均体重 | 周目标 | Slow Carb 日赤字（÷6） | 说明 |
|---:|---:|---:|---|
| 175 lb | 0.88 lb/周 | **511 kcal** | 旧体重参考 |
| 170 lb | 0.85 lb/周 | **495 kcal** | 当前档 |
| 165 lb | 0.83 lb/周 | **481 kcal** | 近地板 |
| 160 lb | **停扩大缺口** | +150–250 kcal 吃回去 | 触地板规则 |

> **0.5% 是「秤上体重」目标，不全是纯脂肪。** 看 **Withings 体脂% 周均** 验证是否在掉脂；若体重降但体脂% 不动，按 `ADJUSTMENT_RULES.md` Case B/C 微调（回热量 + 凑满 4× 力量），不要再砍。

> 体重变化后每 2 周用新晨重确认 BMR；**力量固定按 100 kcal/次**，跑步按 Garmin 实绩。

## 3. Slow Carb 食谱（非 Cheat Day）

邮件必须给出**完整一日清单**（早/午/晚/加餐），每项有 **g/个/杯 + 约 kcal + 约蛋白 g**。  
**按训练日直接套用 §3.1 或 §3.2 固定范例**，再按昨日 Nutrition 缺口微调（例：蛋白差 15 g → 多加 1 勺粉）。

**Slow Carb 硬性排除：** 白米、白面、面包、土豆、水果（跑后 ½ 根香蕉例外）、糖、果汁、奶/酸奶/奶酪、油炸食品、酒精。

**饮料：** 水、黑咖啡、无糖汽水 **不限**。

**调味（照抄可用）：** 盐、黑胡椒、蒜粉、辣椒粉、孜然、柠檬/青柠汁、低钠酱油 **1 茶匙**、苹果醋。

## 4. Cheat Day（周六）

- 全天可吃：披萨、甜点、酒、白碳、奶类等 Slow Carb 禁止项。  
- **不设热量上限**；尽量 **1 日** 而非 spillover 到周日。  
- **Cheat 餐前深蹲 3×10**（自重或轻杠）；其余休息。  
- **周日早餐起** 恢复 Slow Carb 模板；邮件周日须写「Cheat 后回归清单」。  
- 若 Cheat 后周日 Withings 体重升 >2 lb：周日仍正常吃 Slow Carb 档，**不加码缺口**（多半是水分/糖原）。

## 6. 参考公式（Agent 重算用）

```
BMR（男）= 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 5   ← 参考
日常消耗 = Whoop NEAT 档 = 2100                            ← 你校准的值
当日运动：力量 +100 · 跑步 +Garmin · 休息 +0
当日 TDEE = 2100 + 当日运动
周目标减重组(lb) = 当前周均体重(lb) × 0.5%
周赤字 = 周目标减重组 × 3500
Slow Carb 日赤字 = 周赤字 ÷ 6
Slow Carb 日目标摄入 = 当日 TDEE − Slow Carb 日赤字
周六 Cheat：不设上限，不扣赤字
```

**文献：** 阻力训练者减脂约 **0.5–1.0% 体重/周** 较利于保肌；本计划取 **0.5%**（2026-09-03 从 1% 下调），须配合 **160–180 g 蛋白 + 4× 力量**；若连续两周周均降 >1.3 lb 或近 160 lb，按 `docs/ADJUSTMENT_RULES.md` 回热量。
