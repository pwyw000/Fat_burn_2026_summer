### NEAT 是什么？

**NEAT** = *Non-Exercise Activity Thermogenesis*：正式训练以外的日常消耗。  
本计划「日常消耗」= **Whoop 校准 2,100 kcal**（不再用 BMR×1.40），再另加力量 **+100** / 跑步 **+Garmin**。

详细分档与食谱见 `docs/WEEK1_PLAN.md`。

## 阶段目标（硬约束）

| 指标 | 目标 |
|---|---|
| 周速率 | **每周约 −0.5% 体重**（随体重下降重算；用周均体脂% 验证掉的是脂肪） |
| 体脂% | **降到约 12%**（方向性；不设死线日期） |
| 体重地板 | **不得低于 160 lb**（周均 < 160 立刻 +150–250 kcal） |
| 瘦体重 | 尽量保住；**4× 力量 + 160–180 g 蛋白** 优先于加大缺口 |

粗算：瘦体重大致保住时，12% 体脂约 **160–165 lb**。触及 160 lb 地板时，**加豆/慢碳/总热量** 优先于继续砍缺口。
