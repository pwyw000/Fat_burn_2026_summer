# 个人档案（基线）

- 男 · **41 岁** · 身高 **6'0"（72 in / 183 cm）**
- 开局：178.2 lb · BMI ≈ 24.2 · 体脂 20.1%
- 当前参考（2026-07-26）：**175.7 lb · 体脂 ~19.5%**
- 饮食：**Slow Carb Diet**（Mon–Fri + Sun 严格；**周六 Cheat Day**）；在 **Muscle Booster App → Nutrition** 记录并截图
- 训练：**跑步 2×/周（周日 + 周中周三）** · **力量 4×/周（Mon/Tue/Thu/Fri · Muscle Booster 10–20 min）** · **周六休息**
- 恢复：WHOOP（绿/黄/红）指导是否减量
- 蛋白目标：**160–180 g/日**（Slow Carb 日）

## 能量预算（按当前 ~175 lb · 41 岁 · 183 cm）

| 项目 | 数值 |
|---|---|
| BMR（Mifflin–St Jeor） | **≈ 1,735–1,740 kcal/日** |
| TDEE（周均 · 分量法） | **≈ 2,560–2,650 kcal/日** |
| 力量消耗 | **100–200 kcal/次**（非主要赤字来源） |
| 跑步消耗 | **550–750 kcal/次**（Garmin 实绩 · 主要运动消耗） |
| 周减脂目标 | **−1% × 当周均体重/周**（滚动；175 lb → 1.75 lb/周） |
| Slow Carb 日赤字 | **≈ 1,020 kcal**（= 周赤字÷**6**；周六 Cheat 不计） |
| Slow Carb 日摄入（均摊） | **≈ 1,550–1,650 kcal**（力）/ **~2,050**（跑）= TDEE − 上项 |

详细分档与食谱见 `docs/WEEK1_PLAN.md`。

## 阶段目标（硬约束）

| 指标 | 目标 |
|---|---|
| 周速率 | **每周约 −1% 体重**（随体重下降重算；例：175 lb → ~1.75 lb/周） |
| 体脂% | **降到约 12%**（方向性 · 约 2 个月） |
| 体重地板 | **不得低于 160 lb**（周均 < 160 立刻 +150–250 kcal） |
| 瘦体重 | 尽量保住；**4× 力量 + 160–180 g 蛋白** 优先于加大缺口 |

粗算：瘦体重大致保住时，12% 体脂约 **160–165 lb**。触及 160 lb 地板时，**加豆/慢碳/总热量** 优先于继续砍缺口。
